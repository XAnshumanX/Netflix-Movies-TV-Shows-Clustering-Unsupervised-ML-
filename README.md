# Netflix Movies & TV Shows Clustering

I have developed a clustering program in Python that analyzes Netflix movies and TV shows using unsupervised machine learning techniques.

## 💾 Project Files Description

This project includes 1 main Jupyter Notebook file, 1 CSV dataset file, as well as 1 GitHub repository link as follows:

## Main Jupyter Notebook:

Netflix_Movies_TV_Shows_Clustering.ipynb - This notebook includes all functions required for data preprocessing, clustering operations, and exploratory data analysis.

Dataset Overview: Contains information on 7,787 titles, including 12 columns show ID, type (Movie/TV Show), title, director, cast, country, date added, release year, rating, duration, genre listings, and descriptions.



## Output Files:

NETFLIX_MOVIES_AND_TV_SHOWS_CLUSTERING.csv - Contains the dataset with details about Netflix's content, including titles, directors, actors, countries, and descriptions as of 2019.

Netflix_kmeans_model.pkl - This file stores the trained K-Means clustering model, allowing for quick access to clustering functionality without the need to retrain the model.


## GitHub Repository:


GitHub Repository - Houses the code for the clustering model, visualizations, and findings.
📖 Project Summary

This project utilizes a dataset of TV shows and movies available on Netflix as of 2019, collected from Flixable, a third-party Netflix search engine. The dataset reveals interesting trends, including the significant growth in the number of TV shows while the number of movies has decreased.

## The project involves:

Data Exploration: Understanding the dataset and cleaning it for analysis.

Clustering: Forming clusters based on various parameters such as genres and viewer preferences by removing stop words and unnecessary elements to retain important keywords.

Modeling: Using techniques such as the silhouette method and K-Means elbow method to find the optimal number of clusters.

Recommender System: Building a content-based recommender system utilizing cosine similarity to suggest the top ten movies to users.
